# Astro Kundli

Astro Kundli is a web application built using Python and Flask that allows users to enter their birth details and ask a question to receive a generated reading.

## Features
- User input form for name, date of birth, birth time, and birthplace
- Question-based input
- Web interface built with HTML and CSS
- Flask backend for processing user requests

## Tech Stack
- Python
- Flask
- HTML
- CSS
- JavaScript (if used in the project)

## How to Run Locally

1. Clone this repository.
2. Open the project folder in your terminal.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Run the Flask application using the correct entry-point file.
5. Open the local URL shown in your terminal.
